# AI × Data × Storage 产业与技术雷达
日期：2026-11-12
范围：全球 Database / KV / Storage / AI Infrastructure / Agent；中国、美国及国际市场
口径：优先一手来源；区分 GA、Preview、论文预印本和厂商性能声明。

## 本期摘要

1. Neo4j 发布 Relate：Apache-2.0、Rust、内存优先的 Agent 嵌入式图数据库，内置 MCP、CLI、Bolt/HTTP，支持 Cypher、向量与图遍历组合。
2. Agent Substrate 1.0 与 kagent 企业版 GA，CNCF Sandbox 接纳 Agent Substrate、gVisor、OpenRL；Agent Runtime 开始从框架竞争走向基础设施竞争。
3. SGLang 0.5.23、vLLM 0.33.0 持续推进 KV Cache 分层、低精度 KV、HiCache；Supermicro/IBM/NVIDIA 发布持久化 KV Cache 联合方案。
4. Redis Iris 扩展 Agent Memory、Context Gateway、Intent Router 等能力；PhoenixAI Contextbase 进入 Private Preview，争夺 Agent 上下文数据层。
5. 中国电科金仓发布 KES AI 数据库，强调库内语义、推理和安全管控；关键待验证点是语义是否真正进入数据库执行与治理链路。

## 一、数据库与 Agent-native DB

### Neo4j Relate（11 月 11 日，已发布）
Neo4j 发布 Relate，定位为面向 Agent 的开源内存型、进程内嵌入式数据库，使用 Rust 构建，Apache-2.0。提供 MCP Server、CLI、Bolt、HTTP Query API；支持 Cypher、图遍历与向量相似度查询组合。其 Agent 适配包括结构化错误、retryable 标志、结果行数上限和截断标记。官方称内存读取亚毫秒级，属于厂商指标，仍需独立压测。
判断：这是 Agent 本地执行环境数据层的清晰产品信号，不是企业数据库替代品。重点验证 WAL/fsync 与崩溃恢复、事务隔离、多 Agent 并发、状态迁移、资源隔离和审计能力。
来源：https://neo4j.com/press-releases/announcing-relate-by-neo4j/ ；https://relatedb.ai

### PostgreSQL / MySQL
PostgreSQL 19 RC 1 已于 10 月 15 日发布；RC 不宜用于生产。PostgreSQL 官方路线图将 11 月 12 日列为季度 minor release 目标日期，本次检索未核实今天已有新 minor release 正式发布。PostgreSQL 14 于 2026-11-12 停止常规修复，仍在运行的生产环境应规划升级。
PostgreSQL 生态：AgensGraph 2.18 扩展 PostgreSQL 18 上的 ISO GQL；Dasha 1.10 增加 Patroni 自动发现、等待分析和复制槽预测；Brume 2.1 提供外键安全的测试数据脱敏。
Percona 11 月初发布 XtraBackup 9.7.2-2、PXC 8.0.46-39 及 MySQL 9.7.2 相关发行版。
来源：https://www.postgresql.org/about/newsarchive/ ；https://www.postgresql.org/developer/roadmap/ ；https://docs.percona.com/new/

### 中国数据库：电科金仓 KES AI 数据库
电科金仓 10 月 30 日发布 KES AI 数据库，公开报道强调库内语义、库内计算推理和原生安全管控。其语义方案包括为表、字段定义业务含义、关系和计算口径，并由 AI 提出建议、业务人员确认。
判断：企业 Text-to-SQL 的关键瓶颈常常是业务语义、指标口径和权限，而不是 SQL 语法。需要验证语义是否版本化、可审计、可回滚；是否影响优化器或执行过程，还是仅供模型生成 SQL；以及权限、脱敏和操作审批如何实现。
来源：https://www2.xinhuanet.com/tech/20261103/264379af116f4d7eae9b80c01cf7a57d/c.html ；https://www.taiji.com.cn/TaijiCMS/html/gsxw/20261103/4958.html

## 二、Agent 独立专项

### Agent Runtime：基础设施化
Google 宣布 Agent Substrate、gVisor、OpenRL 贡献至 CNCF Sandbox；Agent Substrate 1.0 在 GKE GA。其 Actor 保存 Agent 状态、文件和身份，Worker 来自可复用沙箱池，Gateway 管理访问和凭据。空闲会话可快照并释放 Worker，恢复时重新分配执行环境。Google 宣称恢复低于 500ms、百万级沙箱和约 10 倍容器密度，均属项目方指标。
11 月 10 日 Solo.io 宣布 Agent Substrate 与 kagent 企业版 GA，披露 OutSystems、Swissquote 等生产使用情况。CNCF Sandbox 不等于毕业或成熟度认证。
关键难题：快照一致性、外部副作用恢复、身份连续性、秘密注入、长连接与事务处理、工具调用审计。
来源：https://cloud.google.com/blog/products/containers-kubernetes/open-infrastructure-for-autonomous-agents-comes-to-cncf ；https://www.solo.io/press-releases/announcing-kagent-1-0-ga

### Agent Memory
关注 claude-mem（会话捕获与压缩）、Hindsight（retain/recall/reflect）、Cognee（知识图谱记忆）、Mem0（结构化记忆基础设施）。Star 增长不代表准确率、生产适用性或付费需求；需区分开源 SDK、托管服务和企业版，并核对 benchmark 是否独立复现。
GitHub 项目：https://github.com/thedotmack/claude-mem ；https://github.com/vectorize-io/hindsight ；https://github.com/topoteretes/cognee ；https://github.com/mem0ai/mem0

### Agent 安全
重点从 Prompt 防护转向执行边界：身份层、工具权限、数据权限、执行验证与审计。高风险操作需最小权限、审批绑定、幂等、回滚/补偿和执行前后数据校验。子 Agent 不应继承无限制权限；权限应绑定任务、资源、操作和时间范围。

### GitHub 热度信号
NVIDIA/auto-ontology 提供语义、图推理和确定性查询生成框架，Apache-2.0；agent-browser / agent-desktop 将 Agent 自动化扩展到浏览器和桌面。趋势聚合站数据显示相关项目近期增长较快，但第三方趋势数据仅作发现线索。
来源：https://github.com/NVIDIA/auto-ontology ；https://github.com/vercel-labs/agent-browser ；https://github.com/vercel-labs/agent-desktop

## 三、推理、KV Cache 与存储

SGLang 0.5.23（11 月 2 日）增加 DeepSeek 风格 MLA 模型通过 HiCache 文件型 L3 存储使用 Prefix Cache，并持续推进 CPU KV Cache、PD 分离和长上下文优化。vLLM 0.33.0（11 月 2 日）推进 NVFP4 等低精度 KV Cache、调度和模型支持。
Supermicro、IBM、NVIDIA 11 月 5 日发布联合持久化 KV Cache 方案，组合 Supermicro 全闪存服务器、IBM Storage Scale、NVIDIA Dynamo 和 Spectrum-X。其 120B 模型、130k token 场景最高 56 倍 TTFT 改善属于特定厂商测试，不应外推为通用收益。
技术判断：KV Cache 正形成 HBM、DRAM、本地 NVMe、共享网络存储的分层体系。需要分别考虑 Cache Offload、Cache Sharing、Cache Persistence；三者的索引、传输、一致性和故障恢复目标不同。
重点项目：SGLang HiCache、Mooncake、NVIDIA Dynamo、vLLM KV Cache、LMCache。
来源：https://github.com/sgl-project/sglang/releases ；https://github.com/vllm-project/vllm/releases ；https://www.supermicro.com/en/pressreleases/supermicro-launches-kv-cache-solution-ibm-and-nvidia

长期观察：RDMA/RoCE、SmartNIC、CXL 内存池化、并行文件系统、存储能耗优化。本期没有足够一手证据确认新的 CXL 大规模商业部署，不将其描述为近期落地突破。

## 七、机会判断

1. Agent 数据访问控制与安全执行：SQL/API 验证、资源级权限、审批、幂等、回滚、审计和可重放 Trace。
2. Agent Context Database：统一事实、事件、业务语义、长期记忆、来源版本、执行轨迹、评估结果和权限生命周期。
3. Agent Runtime + 数据库状态管理：Checkpoint 与事务协调、暂停时未提交事务处理、恢复后防止重复副作用、多 Agent 状态隔离。
4. KV Cache 存储产品化：跨推理引擎、GPU 节点和存储后端的统一管理，但必须解决模型兼容、块布局、前缀匹配、版本和一致性，而不只是 GET/SET。

## 八、本期结论与核验纪律

最值得持续跟踪的方向：Agent Runtime、Agent-native DB、Agent Context/Memory、KV Cache Storage、数据库安全执行层。
产业趋势：从“AI 调用数据库”转向“数据库、存储与运行时共同支撑 Agent 自主执行”。
避免误判：Star 不等于生产价值；1.0 不代表所有工作负载适用；厂商极值性能不能外推；MCP 接口不等于 Agent-native；功能集成不等于一致性与治理已经解决。
本报告区分 GA、Preview、论文预印本和厂商声明。未找到可靠一手证据的融资、性能和部署信息不作确定性结论。
