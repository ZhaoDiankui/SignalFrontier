# SignalFrontier

A research archive for the **AI × Data × Storage Industry Radar**.

## Archive layout

- `daily/YYYY/MM/YYYY-MM-DD.md` — daily Chinese research briefings.
- `annual/YYYY/YYYY-MM-DD-topic.md` — annual retrospective and thematic industry reports.
- `weekly/YYYY/YYYY-Www.md` — weekly reviews, when generated.
- `monthly/YYYY-MM.md` — monthly reviews, when generated.
- `companies/` — company profiles and tracking notes.
- `projects/` — open-source projects and product tracking.
- `research/` — papers, conferences, labs, and research notes.
- `technologies/` — technology topics and architecture notes.
- `indexes/` — chronological and topic indexes.

## Publishing rules

Daily reports are archived as Markdown. Existing reports are never silently overwritten. Each published report should retain clickable primary-source links and citations. Indexes are updated incrementally. A failed GitHub publication must be reported as a failure; the generated report must be retained for retry.

All dates and archive paths use the report's publication date.
